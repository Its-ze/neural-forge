# Neural Forge archive

Neural Forge was retired on July 23, 2026. This repository preserves the final
source release for reference and recovery. It is archived and no longer
maintained.

The public browser build and historical Windows release artifacts were published
through the ITSZ GitHub Pages repository during the project's active life.

Development resumed with Zach’s explicit authorization on November 3, 2026. The original July archive remains unchanged in Dropbox; this repository now carries versioned fixes and tests.
